# 面板配置说明

## 🔐 首次登录

### 访问面板

```
http://<服务器IP>:54321
```

上述地址只适用于尚未修改配置的全新数据库。已有数据库沿用原来的端口、路径及账号；启用 HTTPS 时改用 HTTPS 地址。

全新数据库可能初始化以下凭据，实际以所用版本和初始化结果为准：
- **用户名**：`admin`
- **密码**：`admin`

⚠️ **重要**：首次登录后请立即修改默认密码！

## ⚙️ 基础配置

### 1. 修改面板设置

进入 **面板设置** → **面板配置**：

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 面板端口 | 非标准端口（如 8443） | 避免使用常见端口提高安全性 |
| 面板路径 | 自定义路径（如 `/xui-admin`） | 增加路径复杂度防扫描 |
| SSL 证书 | 可选 | 如有域名可启用 HTTPS |

保存后重启面板生效。

### 2. 修改用户凭据

进入 **面板设置** → **用户设置**：

- 修改管理员用户名
- 设置强密码（建议 12 位以上，包含大小写字母、数字、特殊字符）
- 可选：创建多个子账户分配给不同团队成员

## 🚀 添加入站节点（VLESS + Reality + Vision）

### Step 1: 创建入站

1. 点击左侧菜单 **入站列表**
2. 点击右上角 **添加入站** 按钮

### Step 2: 配置协议参数

在弹出的配置窗口中填写：

#### 基本信息
- **协议**：选择 `VLESS`
- **端口**：`443`（或自定义其他端口）
- **备注**：例如 `self-hosted-vless-reality`

#### Reality 配置
- **Reality**：✅ 开启
- **Dest**：`www.cloudflare.com:443`（目标站点示例；请按你的威胁模型和网络策略选择）
- **Server Names**：
  ```
  www.cloudflare.com
  ```
- **Private Key**：点击 **Get New Cert** 自动生成
- **Public Key**：自动生成（客户端需要）
- **Short Ids**：留空或点击生成（建议保留一个空字符串）

#### 客户端配置
展开 **客户端** 选项卡：
- **Flow**：选择 `xtls-rprx-vision`
- 点击 **+** 添加用户
- 设置 UUID（可自动生成）
- 填写邮箱备注（便于识别）

#### 其他设置
- **传输协议**：`TCP`
- **TLS**：无需额外配置（Reality 已处理）
- **嗅探**：✅ 开启（推荐）

### Step 3: 保存并测试

点击底部 **添加** 按钮保存配置。

在入站列表中点击 **操作** → **二维码**，可导出节点信息供客户端使用。

## 📊 流量管理

### 限制单用户流量

在添加入站时，可为每个客户端设置：
- **总流量上限**：例如 100 GB
- **到期时间**：例如 2026-12-31
- **设备数限制**：例如最多 3 台设备

### 查看流量统计

进入 **入站列表**，可查看：
- 实时上传/下载速度
- 累计流量使用情况
- 在线设备数量

### 重置流量

对达到上限的用户，可点击 **操作** → **重置流量**。

## 🔔 Telegram Bot 集成（可选）

如需通过 Telegram 接收通知和管理面板：

### 1. 创建 Bot

1. 在 Telegram 中搜索 `@BotFather`
2. 发送 `/newbot` 创建新机器人
3. 记录获得的 **Token**

### 2. 获取 Chat ID

1. 向你的 Bot 发送任意消息
2. 访问 `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates`
3. 从返回的 JSON 中找到 `"chat":{"id":123456789}`

### 3. 配置面板

进入 **面板设置** → **Telegram**：
- **Bot Token**：填入上一步获得的 Token
- **Chat ID**：填入你的 Chat ID
- **通知开关**：根据需要开启

保存后即可接收：
- 流量预警通知
- 登录提醒
- 系统状态报告

## 🔄 高级配置

### Xray 版本切换

进入 **系统状态** → **Xray 状态**：
- 查看当前版本
- 切换到最新稳定版（推荐）
- 回滚到旧版本（如遇兼容性问题）

### 配置模板

可在 **面板设置** → **Xray 相关设置** 中自定义：
- 日志级别
- 连接超时时间
- 路由规则模板
